Key 如何處理？

API Key 只保存在目前瀏覽器分頁的記憶體中，並用於直接向 Poe API 發送請求。 本頁不會把 Key 儲存在伺服器、localStorage 或資料庫，也不會傳送到 Poe 以外的地方。

關閉或重新整理分頁後，你需要重新輸入 API Key。

取得及使用 Poe API Key

如何取得 API Key：登入 Poe 後，前往 poe.com/api_key （或 poe.com/api/keys），複製 API Key，然後貼到本頁的 API Key 欄位。

免費與收費模型：如要透過 API 呼叫需要點數的收費模型，你需要有有效的 Poe 訂閱或可用點數。免費 Poe 用戶未必能透過 API 使用收費模型；相關請求可能會返回錯誤。圖像、影片和音訊 bot 通常亦會消耗點數。

點數與帳戶：請求會使用你自己的 Poe 帳戶額度或點數。本頁不提供模型額度，也不代你承擔 Poe 的相關費用。

私隱與安全：這是一個靜態前端頁面。API Key 只會保存在目前瀏覽器分頁的記憶體中，並隨請求直接送往 Poe API。本頁不會把 Key 寫入 localStorage，不會上載到你的網站伺服器，也不會傳送到 Poe 以外的地方。關閉或重新整理分頁後，你需要重新輸入 API Key。

注意：模型名稱和可用情況可能隨 Poe 更新而改變。如某個模型出錯，請到 poe.com 確認該 bot 的準確名稱及是否可透過 API 使用。
